# موقع مؤسسة لون للمقاولات العامة

صفحة واحدة، عربي/إنجليزي، بدون خطوة بناء. افتح `index.html` بأي متصفح.

## ما الذي تحتاج تغييره (بالترتيب من الأهم)

### ١. أرقام التواصل ← `assets/js/i18n.js`

في أول الملف تجد كتلة `BIZ`. هذا هو **المكان الوحيد** لأرقام التواصل — تُحقن تلقائياً في بطاقات التواصل والفوتر وزر واتساب العائم ورسالة النموذج.

```js
const BIZ = {
  phoneDisplay: "05X XXX XXXX",   // كما يظهر للزائر
  phoneDial: "+966500000000",     // للاتصال — بدون مسافات
  whatsapp: "966500000000",       // دولي بدون + وبدون صفر البداية
  whatsappDisplay: "+966 5X XXX XXXX",
  email: "info@example.com",
  crNumber: "XXXXXXXXXX",         // السجل التجاري
};
```

> ⚠️ رقم واتساب: لو رقمك `0501234567` اكتبه هنا `966501234567`.

### ٢. الشعار ← `assets/img/logo.svg`

الشعار الحالي **إعادة رسم تقريبية** بناءً على الصورة التي أرسلتها. استبدله بملف SVG الأصلي من مصمم الهوية.

الشعار مرسوم داخل `index.html` مباشرة في ثلاثة مواضع (التنقل، خلفية الهيرو، الفوتر) — ابحث عن `viewBox="0 0 1240 1240"` واستبدل محتوى الـ `<svg>`. احتفظ بـ `fill="currentColor"` حتى يرث اللون من التصميم.

### ٣. مشهد الهيرو ← `assets/frames/`

المشهد **ليس عنصر `<video>`** بل ٦٠ صورة متتابعة تُرسم على `<canvas>`.

**لماذا؟** عنصر الفيديو يعتمد على محرّك الوسائط وفكّ الترميز بالعتاد، وهو يفشل أو يتأجّل في حالات كثيرة خارج سيطرة الموقع (تبويب خلفي، تسريع رسومات معطّل، سياسات المتصفح). الصور تمرّ بمسار مختلف ولا تفشل، والانتقال لأي لحظة فوري بلا بحث ولا إطارات مفتاحية.

**لتغيير المشهد** — ضع الفيديو الجديد ثم:

```bash
ffmpeg -i new-scene.mp4 -vf "fps=6,scale=1280:-2" -q:v 8 assets/frames/f%03d.jpg
```

`fps=6` مع فيديو ١٠ ثوانٍ يعطي ٦٠ إطاراً. لو تغيّر العدد، عدّل `FRAME_COUNT` في أعلى `assets/js/hero-scene.js`، وعدّل `.hero { height }` بمعدل `16vh` لكل ثانية.

> الحالي: ٦٠ إطاراً، ٣ ميجابايت، ٥١ ك.ب للإطار.
> ملفات الفيديو في `assets/video/` لم تعد مستخدمة — احتفظ بها كمصدر أو احذفها.

### ٣ب. (مرجع) ضغط فيديو ← `assets/video/hero.mp4`

المشهد **لا يُشغَّل بنفسه**. هو صورة ساكنة حتى يبدأ الزائر بالتمرير، ثم يتقدّم مع حركته حتى ينتهي عند أسفل قسم الهيرو تماماً.

لاستبداله: ضع ملفك باسم `hero.mp4` في نفس المجلد. ثم اضبط طول التمرير حسب مدة الفيديو من `styles.css`:

```css
.hero { height: 260vh; }   /* ← مسافة التمرير التي يُفرد عليها المشهد */
```

القاعدة: كل ثانية من الفيديو تحتاج تقريباً `16vh` من التمرير. الفيديو الحالي ١٠ ثوانٍ ← ١٦٠vh تمرير فعلي + ١٠٠vh للشاشة الثابتة = **٢٦٠vh**. فيديو ٦ ثوانٍ ← `196vh`.

> ### ⚠️ أهم قاعدة: أي فيديو تضعه هنا **يجب** إعادة ترميزه أولاً
>
> الملف الأصلي كان فيه **إطار مفتاحي واحد فقط** لكامل الـ ٢٤٠ إطاراً. لعرض
> أي لحظة كان المتصفح يفكّ الترميز من البداية في **كل** عملية بحث — فيتجمّد
> المشهد في كروم تماماً. هذا سبب شائع جداً في مخرجات مولّدات الفيديو.

```bash
ffmpeg -i input.mp4 -an -c:v libx264 -crf 24 -preset slow -g 6 -keyint_min 6 -sc_threshold 0 -pix_fmt yuv420p -movflags +faststart hero.mp4
```

| المُعامل | لماذا |
|---|---|
| `-g 6 -keyint_min 6 -sc_threshold 0` | إطار مفتاحي كل ٦ إطارات (٠.٢٥ث) بشكل ثابت. **هذا هو المُعامل الحاسم.** |
| `-an` | يحذف الصوت — غير مستخدم، والفيديو صامت |
| `+faststart` | يضع فهرس الملف في أوله فيبدأ العرض قبل اكتمال التحميل |

**للتحقق من أي ملف قبل استخدامه:**

```bash
ffprobe -v error -select_streams v:0 -show_entries frame=key_frame -of csv=p=0 hero.mp4 | find /c "1"
```

الرقم الناتج هو عدد الإطارات المفتاحية. لو كان ١ أو ٢ فالفيديو **لن يعمل** مع التمرير مهما كان الكود سليماً.

> الملف الحالي: ٣.٤٧ ميجابايت، ٤٠ إطاراً مفتاحياً، أسوأ حالة فكّ ترميز ٧ إطارات.
> النسخة الأصلية محفوظة باسم `hero-original-backup.mp4` — احذفها متى شئت.

### ٤. قسم «قبل / بعد» ← `index.html` قسم `#reveal`

الجدار الحالي **مرسوم بـ CSS** لا صورة — حتى لا يدّعي الموقع مشروعاً لم يُنفَّذ.

لاستبداله بصورتين حقيقيتين، صوّر **نفس الجدار من نفس الزاوية** قبل وبعد، ثم استبدل محتوى `.reveal__wall--before` و`.reveal__wall--after` بـ `<img>`، مع إبقاء `clip-path` على طبقة «بعد». احذف عناصر `.reveal__crack` وسطر `.reveal__hint`.

### ٥. صور المشاريع ← `index.html` قسم `#work`

الصور الحالية مؤقتة من Unsplash، **تم التحقق من محتوى كل واحدة بصرياً**. التسميات تصف نوع العمل لا مشروعاً بعينه — عند وضع صورك الحقيقية غيّرها لأسماء المشاريع الفعلية.

لاستبدالها:

1. ضع صورك في `assets/img/projects/`.
2. في كل `<button class="gallery__item">` غيّر:
   - `data-full` ← الصورة بالحجم الكامل
   - `src` ← نسخة أصغر للعرض في الشبكة
   - `width` و`height` ← **الأبعاد الحقيقية للصورة** (مهم: يمنع اهتزاز التخطيط أثناء التحميل)
   - `alt` ← وصف حقيقي لمحتوى الصورة

3. غيّر النصوص المقابلة في `i18n.js` تحت المفاتيح `work.1.cap` / `work.1.alt` … إلخ (للغتين).

> استبدال هذه الصور بصور مشاريعك الحقيقية هو **أكبر رافعة لمصداقية الموقع**.

### ٦. الأرقام في «من نحن» ← `index.html`

```html
<div class="stat__num tabular" data-count="12">0</div>
```

غيّر `data-count` إلى رقمك الحقيقي. `data-suffix` يضيف `+` أو `%`.

### ٧. النصوص ← `assets/js/i18n.js`

كل نص في الموقع له مفتاح في `I18N.ar` و`I18N.en`. عدّل القيمة في اللغتين معاً.

### ٨. الألوان والثيم ← `assets/css/styles.css`

كل ألوان الموقع رموز في أعلى الملف، وتوجد نسختان: `:root` للداكن و`:root[data-theme="light"]` للفاتح. تغيير الرمز يغيّر كل مكان يستخدمه.

**الهوية:** ذهبي دافئ (`--brand`) على محايد دافئ، و**الأحمر محجوز للشعار وحده** عبر `--logo`.

اللوحة مشتقة من قاعدة `ui-ux-pro-max` — صفوف *Construction/Architecture* و*Architecture/Interior* و*Home Decoration*. بنيتها الثلاث واحدة: **محايد يحمل الواجهة + لمسة دافئة واحدة**. واخترت الذهبي لا البترولي لأنه جار للأحمر على عجلة الألوان فينسجم مع الشعار، بينما المُكمّل يزاحمه.

| الرمز | الاستخدام |
|---|---|
| `--brand` | النصوص والخطوط والأيقونات وحلقة التركيز |
| `--brand-solid` | **تعبئة** الأزرار |
| `--on-brand` | نص الزر — أبيض في الفاتح، **داكن** في الداكن فوق الذهبي |
| `--logo` | الشعار لا غير |
| `--bg` / `--surface` | سطحا الأقسام المتناوبان |
| `--fg` / `--muted` | النص الأساسي والثانوي |
| `--fg-rgb` / `--bg-rgb` | تُولّد الشعيرات والتظليل فتنقلب مع الثيم تلقائياً |
| `--on-scrim` | النص فوق الصور (ثابت فاتح لأن الحجاب ثابت داكن) |

> ⚠️ **الفرق بين `--brand` و`--brand-solid` مهم.** الأول للنص والخطوط، الثاني للتعبئة فقط. ولا تثبّت لون نص الزر — الذهبي الفاتح في الوضع الداكن يحتاج نصاً داكناً لا أبيض.

**زر الثيم** في شريط التنقل. الاختيار يُحفظ في `localStorage`، وبلا اختيار يتبع الموقع إعداد الجهاز. الثيم يُطبَّق في `<head>` قبل أول رسم حتى لا يومض.

## معاينة محلية

افتح الموقع عبر خادم لا بـ `file://` — الأخير يسبب سلوكاً غريباً مع الوسائط ويمنع بعض الأدوات:

```bash
npx --yes serve "C:\Users\amin1\OneDrive\سطح المكتب\Website" -l 8080
```

> ⚠️ ترتيب السكربتات في `index.html` مقصود: `coverflow.js` **قبل** `motion.js`.
> مستمع النقر على البطاقات يجب أن يُسجَّل أولاً ليمنع فتح العارض عند
> النقر على بطاقة جانبية أو بعد سحب. عكس الترتيب يكسر هذا السلوك.

## شريط التنقل

الشريط **مخفي ما دام مشهد الهيرو يُعرَض**، ويظهر بانزلاق بعد أن يمرّ الهيرو. شريط صلب فوق اللقطة كان يقطعها.

المنطق في `motion.js`: `hero.getBoundingClientRect().bottom <= 80`. لتغيير لحظة الظهور عدّل الرقم — أو استبدل الشرط بـ `window.scrollY > 80` لو أردته يظهر فور أول تمرير.

> يُخفى بـ `transform` و`opacity` لا بـ `display:none`، فيبقى في شجرة إمكانية الوصول. وقاعدة `.nav:focus-within` تُظهره فور وصول مستخدم لوحة المفاتيح إليه بـ Tab، حتى لا يكون مخفياً تحت أصابعه.

## ضبط حجاب الهيرو

الطبقة الداكنة فوق المشهد في `.hero__scrim`. **ليست تدرّجاً يغطي العرض كله** بل بركة مركّزة خلف النص — التدرّج الخطي كان مضطراً للبقاء ثقيلاً عبر ٥٨٪ من العرض لأن كتلة النص عريضة، فيحجب المشهد كله.

الكثافة محلولة بقياس ٢٠١٦٠ بكسل من الإطارات الستين، بنطاقات نص واقعية:

| العنصر | أسوأ تباين | المطلوب |
|---|---|---|
| عنوان القسم (13px ذهبي) | 5.39 | 4.5 |
| العنوان الضخم | 6.00 | 3.0 |
| المتن | 9.13 | 4.5 |

**متوسط الحجاب: ٥٠٪** بعد أن كان ٧٠٪، والجهة البعيدة عن النص تنزل إلى الصفر تقريباً.

> ⚠️ **البيضاوي ممتدّ رأسياً (70%) عمداً.** النسخة الأضيق رأسياً كانت أخف (٤١٪) لكنها رسمت قوساً مرئياً في السماء — السماء سطح أملس يُظهر أي حدّ. بامتداده رأسياً تخرج حوافه عن الشاشة فلا يبقى إلا انحدار أفقي ناعم.
>
> **العنصر الحاكم هو عنوان القسم الصغير**، لا المتن. وللجوال قاعدة منفصلة لأن النص يملأ العرض هناك.
>
> لو غيّرت إطارات المشهد إلى صور أفتح، **أعد القياس**.


## ضبط معرض الأعمال

الإعدادات في أعلى `assets/js/coverflow.js`:

| الثابت | المعنى | الافتراضي |

## قرارات تقنية

**لا Tailwind.** الخطة الأصلية كانت Tailwind عبر CDN، لكن نسخة الـ CDN تطبع تحذيراً في الـ console وتضيف حِملاً غير مستخدم. مع صفحة واحدة بهذا الحجم، CSS مكتوب مباشرة أوضح وأخف ولا يعتمد على شبكة خارجية. النتيجة نفسها بلا اعتمادية.

**الحركة طبقة منفصلة.** `motion.js` يُحمَّل أخيراً فوق صفحة تعمل بدونه. لو فشل تحميل GSAP من الـ CDN، السكربت يكتشف ذلك ويُظهر كل المحتوى فوراً بدل أن تبقى الصفحة فارغة.

**RTL بخصائص منطقية.** الاتجاه يُقلب عبر `margin-inline`, `padding-inline`, `inset-inline` — لا ملف CSS منفصل للعربي.

**النموذج بلا خادم.** يفتح واتساب برسالة مُعبّأة. لتوصيله ببريد إلكتروني بدلاً من ذلك: أنشئ نموذجاً على [formspree.io](https://formspree.io)، ثم في `motion.js` استبدل كتلة `window.open(...)` بـ `fetch` إلى رابط Formspree.

## استبدال صور الخدمات

الصور في `assets/img/services/` — ستّ صور بأسماء ثابتة:

| الملف | الخدمة |
|---|---|
| `interior.jpg` | دهانات داخلية |
| `exterior.jpg` | دهانات خارجية |
| `decor.jpg` | ديكورات وتشطيبات |
| `gypsum.jpg` | جبس بورد |
| `restore.jpg` | ترميم وصيانة |
| `plaster.jpg` | لياسة |

**للاستبدال:** احفظ صورتك بنفس الاسم مكان القديمة. المقاس المستعمل **900×620**، ويُقصّ تلقائياً لأي نسبة قريبة.

**الصور الحالية مؤقّتة** — مرخّصة للاستعمال التجاري وتُظهر نوع التشطيب، لكنها ليست من أعمال المؤسسة. استبدلها بصور مشاريعك الحقيقية متى توفّرت، أو بصور المنتجات الرسمية من الموزّع (Jotun / National) إن كنت معتمداً لديهم — لا تأخذ صور الكتالوجات من الإنترنت مباشرة، فحقوقها محفوظة للشركة المصنّعة.

**ولا تنسَ النصّ البديل:** مفاتيح `svc.img.*` في `assets/js/i18n.js` تصف كل صورة باللغتين. لو بدّلت الصورة، بدّل وصفها معها.

> ⚠️ لو كانت صورتك الجديدة **أفتح** من الحالية، أعد قياس حجاب رمز `LN·0X`.
> القيمة الحالية 0.62 مقاسة على أسطع بكسل في الصور الستّ — انظر التعليق
> فوق `.swatch__chip::after` في `styles.css`.
